## 📖 Descripción

**Sequito** es la evolución definitiva del asistente de combate para WotLK. Inspirado en el legendario **Necrosis**, Sequito lleva esa funcionalidad a **las 10 clases** del juego.

En esta versión **v8.0.0**, hemos implementado **14 módulos nuevos** para PvP, Dungeons y funcionalidades generales, completando todas las 20 funcionalidades planificadas.

### 🎯 Funcionalidades Core

- ✅ **Soporte Universal Completo**: Macros inteligentes para TODAS las clases y specs.
- 🔧 **Panel de Opciones Real**: Configura Escala, Transparencia, Alertas y Combate.
- 📊 **Combat Tab**: Nueva pestaña para configurar el rastreo de DPS/HPS y resúmenes.
- 🔮 **Esfera Necrosis**: Réplica visual y funcional, con botones satélite y menú contextual.
- 🔄 **Macros "Elite"**: Generación automática de macros con lógica condicional.
- 👥 **Raid Panel**: Panel de raid configurable (Roles, HP, Clase) con auto-apertura.
- ⚔️ **Alertas Tácticas**: Avisos visuales y sonoros para CC roto, vida baja y cooldowns.
- 🗺️ **Minimapa**: Botón de acceso rápido móvil y configurable.
- 🌓 **Runas DK**: Visualización de runas integrada y opcional.

### 🆕 Nuevo en v8.0.0 - 14 Módulos Nuevos

#### ⚔️ PvP (4 módulos)
- **FocusFire**: Llamadas de target sincronizadas con el grupo.
- **CCCoordinator**: Coordinador de CC con tracking de Diminishing Returns.
- **HealerTracker**: Monitor de mana de healers enemigos.
- **DefensiveAlerts**: Botones rápidos para pedir peel/heal/dispel.

#### 🏰 Dungeons (3 módulos)
- **PullGuide**: Guía de pulls con marcado automático por prioridad.
- **DungeonTimer**: Timer de reset de heroicas con lista de completadas.
- **LootCouncil**: Sistema de votación de loot para guilds.

#### 👥 General (7 módulos)
- **PlayerNotes**: Notas sobre jugadores compartibles con el guild.
- **BuildManager**: Gestor de builds/specs con guardado y carga rápida.
- **EventCalendar**: Calendario de eventos del guild integrado.
- **PerformanceStats**: Estadísticas de DPS/HPS por boss.
- **VotingSystem**: Sistema de votaciones rápidas en tiempo real.
- **VersionSync**: Sincronización de versiones del addon.
- **QuickWhisper**: Mensajes rápidos predefinidos con keybinds.

### Nuevo en v7.2.0

- ⚔️ **TrinketTracker (PvP)**: Detecta y trackea trinkets PvP enemigos con timer de 2 min.
- 💀 **WipeAnalyzer (PvE)**: Análisis detallado de wipes - quién murió primero, por qué, consumibles usados.

### Nuevo en v7.1.0

- 🚨 **Alertas Personalizables**: Posición configurable (TOP/CENTER/BOTTOM) con sonidos.
- 📜 **Historial de Wipes**: Estadísticas detalladas guardadas en SavedVariables.
- 🔄 **MacroSync**: Sistema de macros compartidos entre usuarios de Sequito.
- 📚 **Biblioteca de Macros**: Macros predefinidos por clase (10 clases, 3-5 macros c/u).

## 📦 Instalación

1. Descarga el addon.
2. Extrae la carpeta `Sequito` en `Interface/AddOns/` de tu cliente WoW 3.3.5a.
3. Asegúrate de borrar cualquier versión anterior para limpiar configuraciones corruptas.
4. Reinicia WoW.

## 🚀 Inicio Rápido

```
/sequito options   - Abre el NUEVO panel de configuración
/sequito macros    - Genera las macros inteligentes para tu clase
/sequito reset     - Resetea la configuración por defecto
/sequito help      - Muestra la lista de comandos
```
